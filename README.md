# Eldes Gate для Home Assistant

Первая версия интеграции на основе приложения AppDaemon `eldes_gate (1).py`.
AppDaemon, Selenium и ручное создание input_button/input_boolean не требуются.

## Возможности

- Настройка логина, пароля, ID устройства и длительности индикатора через интерфейс HA.
- Кнопка «Ворота» отправляет C1=1, кнопка «Калитка» — C2=1.
- Для каждого выхода доступны датчик отправки команды, датчик ошибки и датчик открытия.
- Можно выбрать существующий binary_sensor HA отдельно для ворот и калитки: on = открыто, off = закрыто.
- Без выбранного датчика индикатор открытия повторяет таймер команды, как в исходном скрипте.
- Выбор датчиков и длительность таймера меняются через «Настроить» в карточке интеграции.
- Повторное нажатие во время операции отклоняется; автоматического повтора команды нет.
- Ошибка сохраняется до следующего нажатия или перезагрузки интеграции.

**Без выбранного датчика положение ворот неизвестно.** Индикатор отправки включён во время запроса и,
при успешном ответе, до истечения указанного времени с начала операции (по умолчанию 30 секунд).
Без контакта это не подтверждение положения. Сущность cover не создаётся.
Если выбранный контакт недоступен, индикатор открытия также недоступен; таймер его не подменяет.
Очистка выбора контакта в настройках возвращает режим таймера.

## Установка вручную

1. Скопируйте папку `custom_components/eldes_gate` в `/config/custom_components/eldes_gate` вашей HA.
2. Перезапустите Home Assistant.
3. Откройте «Настройки → Устройства и службы → Добавить интеграцию → Eldes Gate».
4. Введите данные портала https://security.eldes.lt и ID из адреса страницы управления `device/control/?id=...`.
5. Проверьте назначение C1/C2 для вашего устройства перед нажатием кнопок.

## Установка через HACS

1. В HACS откройте меню ⋮ → «Пользовательские репозитории».
2. Добавьте `https://github.com/ipmerlin/eldes-gate`, тип «Интеграция».
3. Найдите Eldes Gate и скачайте последнюю версию.
4. Перезапустите Home Assistant и добавьте интеграцию через «Настройки → Устройства и службы».

[Добавить репозиторий в HACS](https://my.home-assistant.io/redirect/hacs_repository/?owner=ipmerlin&repository=eldes-gate&category=integration)

Репозиторий устанавливается как пользовательский; в общий каталог HACS он ещё не включён.

## Иконки и логотип

Ворота и калитка имеют разные иконки; датчики показывают значки открытого и закрытого состояния.
Для отправки команды и ошибок также предусмотрены отдельные иконки.
Логотип Eldes поставляется внутри интеграции. Его отображение требует HA 2026.3 или новее.
После обновления через HACS перезапустите HA и обновите страницу браузера.
Если вручную задана своя иконка сущности, очистите это поле для применения иконки интеграции.

## Ограничения и проверка

Клиент использует веб-форму Eldes и извлекает deviceKey/userid, как исходный скрипт.
Это не документированный официальный API: изменение портала может нарушить работу.
HTTP-ошибки, возврат на страницу входа, некорректный JSON, поле error и success=false
обрабатываются как ошибки. Точная схема положительного подтверждения Eldes в исходнике
не описана; JSON-ответ сам по себе не доказывает выполнение команды устройством.

Пароль хранится в конфигурационной записи HA. Не публикуйте конфигурацию учётной записи.
Ключи устройства и ответы портала не выводятся в журналы интеграции.
Изменение данных в этой версии: удалить интеграцию и добавить заново.

Локальная проверка: `python scripts/check.py`. Она проверяет синтаксис, JSON,
парсинг форм и управление командным запросом на имитации портала без обращения к воротам.
Запуск внутри настоящей HA и работа реального портала ещё не проверены.
