# Eldes Gate 0.1.0

Первая версия интеграции Home Assistant для установки через пользовательский репозиторий HACS.

- Настройка через интерфейс HA: логин, пароль, ID устройства.
- Кнопки управления воротами (C1) и калиткой (C2).
- Выбор отдельного датчика открытия HA для каждого выхода.
- Индикация по таймеру, если датчик не выбран.
- Датчики отправки команды и ошибки, русские и английские подписи.

Локальные проверки синтаксиса, JSON, обработки ответов портала и состояний датчиков пройдены.
Работа внутри реальной Home Assistant и с устройством Eldes ещё не проверена.
Интеграция использует веб-портал Eldes; ответ на команду не подтверждает физическое движение ворот.
